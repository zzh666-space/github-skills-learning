# github-skills-learning

GitHub Skills 全套课程学习仓库，使用真实 GitHub 仓库逐课练习 Git & GitHub 工作流。

## 课程路线

| 序号 | 课程 | 核心主题 | 状态 |
|------|------|----------|------|
| 1 | [Introduction to GitHub](https://github.com/skills/introduction-to-github) | 仓库、分支、提交、Pull Request | ✅ 已完成 |
| 2 | [Introduction to Git](https://github.com/skills/introduction-to-git) | Git 基础、版本控制 | ⏳ 待开始 |
| 3 | [Communicate using Markdown](https://github.com/skills/communicate-using-markdown) | Markdown 语法与写作 | ⏳ 待开始 |
| 4 | [Hello GitHub Actions](https://github.com/skills/hello-github-actions) | CI/CD 流水线 | ⏳ 待开始 |
| 5 | [GitHub Pages](https://github.com/skills/github-pages) | 静态站点部署 | ⏳ 待开始 |
| 6 | [Release-based workflow](https://github.com/skills/release-based-workflow) | 版本发布工作流 | ⏳ 待开始 |
| 7 | [Secure your repository](https://github.com/skills/secure-repository-supply-chain) | 仓库安全与供应链 | ⏳ 待开始 |

## 学习规则

- 每课创建独立 feature 分支，遵守 Conventional Commits 规范
- 需要 PR 的环节正常创建 PR，合并后再进入下一课
- 每课输出学习笔记，全部课程结束后输出总结报告
- 所有文档存放于 `docs/` 目录，使用标准 Markdown 编写
